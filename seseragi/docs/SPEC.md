# せせらぎ (Seseragi) 仕様書

## 1. コンセプト

> 雨音とピアノを、かさねて眠る。

眠るときに「雨の音」と「好きなピアノ曲」を同時に流したい——
そのための、**2つの独立した音の流れを1つの画面で操るプレイヤー**。

ビジュアルは**清流**。深い青緑のグラデーションの上を、静かな波がゆっくり流れる。
夜に見ても眩しくないダークトーンで統一する。

## 2. 用語

| 用語 | 意味 |
|---|---|
| デッキ（ながれ） | 独立した1系統のプレイヤー。本アプリには「ながれ A」「ながれ B」の2つがある |
| キュー | デッキに読み込まれた曲のリスト（＝そのデッキのプレイリスト） |

## 3. 機能要件

### F-1. 2デッキ並列再生
- 2つのデッキが**同時に**音声を再生できる。
- 片方だけの再生、両方の再生、どちらも自由に行える。
- 一方のデッキ操作が他方の再生に影響しない。

### F-2. 選曲（ミュージックライブラリ連携）
- デッキごとに iPhone のミュージックライブラリ（`MPMediaPickerController`）から曲を選べる。
- 複数曲の同時選択に対応し、選んだ曲がそのままデッキのキューになる。
- 選曲するとそのデッキは自動的に再生を開始する。
- 再生できない曲（後述の DRM 制約）は自動で除外し、除外した曲数をアラートで通知する。

### F-3. 音量調整（デッキ独立）
- デッキごとに 0〜100% の音量スライダーを持つ。
- 音量変更は再生中に即時反映される。
- 端末のマスター音量とは独立した、アプリ内ミックスバランスとして機能する。

### F-4. リピート（デッキ独立）
- デッキごとに以下の3モードをボタンで巡回切替できる。
  1. **プレイリストリピート**（初期値）: キューの最後まで再生したら先頭に戻る
  2. **一曲リピート**: 現在の曲を繰り返す
  3. **リピートなし**: キューの最後の曲が終わったら停止する

### F-5. 再生操作（デッキ独立）
- 再生 / 一時停止
- 次の曲へスキップ
- 前の曲へ（再生位置が3秒を超えている場合は曲頭に戻る。3秒以内なら前の曲へ）
- 現在の曲名・アーティスト名・アートワーク・再生位置 / 曲の長さ・「n / m 曲」を表示する。

### F-6. 全体操作
- 「すべて再生 / すべて一時停止」ボタンで両デッキをまとめて操作できる。

### F-7. おやすみタイマー
- 15 / 30 / 45 / 60 / 90 分のプリセットから選択。
- 残り時間を mm:ss で表示。途中解除が可能。
- 終了前の最後の20秒で両デッキの音量をゆっくりフェードアウトし、その後一時停止する。
- フェードはユーザーが設定した音量バランスを壊さない（内部係数で減衰し、解除時に元へ戻る）。

### F-8. バックグラウンド再生・ロック画面
- 画面を消しても、他アプリに切り替えても再生が続く（`UIBackgroundModes: audio`）。
- ロック画面 / コントロールセンターに再生情報を表示する（両デッキの曲名を「曲A ✕ 曲B」形式で連結表示）。
- ロック画面の再生 / 一時停止ボタンは**両デッキ一括**で作用する。
  （システムの Now Playing は1系統しか扱えないため、曲送りボタンは無効化する）

### F-9. 権限ハンドリング
- 初回起動時にミュージックライブラリへのアクセス許可（`NSAppleMusicUsageDescription`）を要求する。
- 拒否された場合は説明と「設定を開く」ボタンを表示する。

### F-10. 割り込み処理
- 電話着信などのオーディオ割り込みが発生したら両デッキを一時停止する。

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応 OS | iOS 17.0 以降 |
| UI フレームワーク | SwiftUI |
| 外部依存 | なし（Apple 標準フレームワークのみ: AVFoundation / MediaPlayer） |
| 画面向き | 縦固定 |
| 外観 | ダーク固定（就寝時の使用を想定） |

## 5. 画面仕様

1画面構成。上から:

```
┌─────────────────────────┐
│        せせらぎ            │  ← タイトル
│  ふたつの流れを、かさねて眠る │
│ ┌─────────────────────┐ │
│ │ 〰 ながれ A     [選曲] │ │  ← デッキカード A（水色）
│ │ [🎨] 曲名             │ │     アートワーク・曲情報
│ │      アーティスト  1/12 │ │
│ │ ▬▬▬▬▬▬░░░░  1:23/4:56 │ │     進行バー
│ │  🔁   ⏮  ▶️  ⏭        │ │     リピート・スキップ・再生
│ │  🔈 ──────●──── 🔊    │ │     音量スライダー
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │ 〰 ながれ B     [選曲] │ │  ← デッキカード B（若草色）
│ │        （同上）         │ │
│ └─────────────────────┘ │
│ [▶ すべて再生]  [🌙 タイマー] │  ← 全体操作バー
└─────────────────────────┘
       背景: 清流（波のアニメーション）
```

### 状態
- **権限未許可**: デッキの代わりに説明カードと「設定を開く」を表示
- **キューが空のデッキ**: 「ミュージックから曲を選ぶ」の大きなボタンを表示
- **タイマー作動中**: ボタンに残り時間（例「おやすみ 12:34」）を表示

### カラー
- 背景: 深い青〜青緑のグラデーション + 半透明の波レイヤー3枚がゆっくり流れる
- デッキ A: 水色系 / デッキ B: 若草色系（清流の水面と岸辺のイメージ）
- カードは `ultraThinMaterial`（すりガラス）で水の透明感を表現

## 6. 制約事項（重要）

### DRM 保護された曲は再生できない

| 曲の種類 | 再生 |
|---|---|
| iTunes Store で購入した曲 | ✅ |
| CD 取り込み・PC から同期した曲 | ✅ |
| ファイル転送した DRM フリー曲 | ✅ |
| Apple Music（サブスク）のストリーミング曲 | ❌ |
| Apple Music の曲をダウンロードしたもの | ❌ |
| iCloud 上にあり端末未ダウンロードの曲 | ❌ |

**理由**: 2曲の同時再生・独立音量には `AVAudioPlayer` が必要だが、
`AVAudioPlayer` はファイル（`MPMediaItem.assetURL`）に直接アクセスするため
DRM 保護された曲を扱えない。DRM 曲を再生できる唯一の手段である
`MPMusicPlayerController` は、1アプリから同時に1系統しか再生できないため
本アプリの中核要件（並列再生）と両立しない。

**実装上の扱い**:
- ピッカーでは `showsCloudItems = false` により未ダウンロードの曲を非表示
- 選択後も `assetURL == nil` または `hasProtectedAsset == true` の曲を除外し、件数を通知

### その他
- シミュレータにはミュージックライブラリが存在しないため、動作確認は実機で行う。
- おやすみタイマーは再生中のみ正確に動作する（オーディオ再生がアプリをバックグラウンドで生かし続けるため。両デッキ停止中はタイマーが遅延する可能性がある）。

## 7. 将来の拡張候補

- 進行バーのドラッグによるシーク

- MusicKit 連携: 片方のデッキのみ `MPMusicPlayerController` にして Apple Music 曲 + 内蔵環境音の組み合わせを可能にするハイブリッドモード
- デッキ構成（選曲・音量・リピート）のプリセット保存
- 曲間クロスフェード
- AirPlay 出力の明示的な切替 UI
- iPad /横向きレイアウト対応
