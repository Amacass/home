# VideoTriage

写真ライブラリの動画を、スワイプだけで「いる / いらない」に高速で振り分ける自分専用 iPhone アプリ。

- **右へスワイプ（右上）= いらない** → あとでまとめて削除
- **左へスワイプ（左上）= いる** → 「いる」アルバムへ振り分け
- 振り分けると **次の動画が即時に自動再生**（ループ再生）
- 下のボタンでも操作可（いる / いらない / ひとつ戻る）
- 右下のスピーカーで音のオン・オフ
- 最後の画面で「実行する」を押すと、いるをアルバムへ追加し、いらないを削除（削除時はiOSの確認ダイアログが出る）

## 必要なもの

- Mac + Xcode 16 以降
- iPhone 実機（iOS 17 以降）。※シミュレータには写真がほぼ無いので実機推奨

## ビルドして実機で動かす手順

1. `VideoTriage.xcodeproj` を Xcode で開く
2. プロジェクト設定 → ターゲット **VideoTriage** → **Signing & Capabilities**
   - **Team** に自分の Apple ID を選ぶ（無料の個人 Apple ID でOK）
   - **Bundle Identifier** が他と被ったら適当に変える（例: `com.あなたの名前.VideoTriage`）
3. iPhone を USB 接続し、上部のデバイス選択で自分の iPhone を選ぶ
4. ▶︎ を押してビルド＆インストール
5. 初回は iPhone 側で「設定 → 一般 → VPN とデバイス管理」から自分の開発者証明書を信頼
6. アプリを起動 → 写真へのアクセスを「許可」

> 無料の個人 Apple ID で署名した場合、アプリは約 7 日で期限切れになります。切れたら Xcode から再インストールすれば復活します。

## 使い方

1. 起動すると動画が1本ずつ自動再生される
2. 右へフリック = いらない / 左へフリック = いる
3. 全部振り分けると集計画面になる
4. 「実行する」→ いるは「いる」アルバムへ、いらないは削除

## 構成

| ファイル | 役割 |
|---|---|
| `VideoTriageApp.swift` | アプリのエントリポイント |
| `VideoLibrary.swift` | 写真ライブラリの取得・振り分け状態・アルバム追加・削除 |
| `PlayerController.swift` | 動画の読み込みと自動ループ再生（`AVPlayer`） |
| `SwipeCard.swift` | スワイプUIのカード |
| `ContentView.swift` | 画面遷移（許可 / 振り分け / 集計） |

写真へのアクセス用途説明はビルド設定の `INFOPLIST_KEY_NSPhotoLibraryUsageDescription` に入れているので、別途 Info.plist は不要です。
